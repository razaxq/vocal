# 精选网络热词

词库由 Vocal 维护，见 `src/shared/network-hotwords.json`。初始 208 个词由项目人工整理，未整包复制第三方输入法词库。它是常用网络词与新词的精选集合，不是实时热搜榜。

## 使用与更新

- 网络热词与个人热词分别保存，默认启用网络词及自动更新。
- 每周从本仓库 main 分支的词库文件检查更新；下载成功后缓存到用户数据目录，断网时保留本地版本。失败后运行期间每天重试，重新启动也可重试。
- 关闭网络词会停止自动检查；仍可手动更新。关闭自动更新不影响本地词库使用。
- 两类词去重合并，个人词加权 2.5，网络词 1.5。同名词保留个人权重。
- 仅支持热词的识别模型使用这些权重。启用「清理时保留热词」时，两类词也纳入口语清理保护。
- 录音或定稿期间不切换词表，等待当前输入完成再应用。
- 这些权重是保守初值，并非准确率最优的测试结论；增加词条后应对照测试含目标词和普通同音词的语音。

## 维护词库

1. 编辑 JSON 的 `words`，每个条目只写词语，不写拼音、解释或权重。
2. 保持 1–500 个条目，每条 2–32 个字符。允许汉字、英文字母、数字、空格、间隔号和连字符。不要加入整段热搜标题。
3. 去重，增加整数 `version`，更新 `updatedAt`；同版本内容必须一致。
4. 运行 `npm test`、`npm run build` 和 `npm run m0:capture`，通过后提交到 main。

已安装的客户端可独立更新词库，无需重新下载模型或等待软件发版。词库文件只作为数据处理，不接受可执行内容或识别引擎的分隔符语法。

以后引入外部词库时，应记录具体来源和适用许可，并经筛选后合入；不直接把大型输入法词库整体作为识别热词。
