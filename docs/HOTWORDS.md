# 雾凇基础词库与个人热词

## 来源

基础词库来自 [iDvel/rime-ice](https://github.com/iDvel/rime-ice) 的 `cn_dicts/base.dict.yaml`，遵循上游 GPL-3.0 许可。原始词典、许可证全文和派生词表单独保存在 `resources/dictionaries/rime-ice/`，随软件分发。

`catalog.json` 记录原始提交 SHA、文件 SHA-256、词库日期、候选数和筛选规则。Vocal 从原词典中保留 3–12 个常用汉字组成的词，去重后按原始词频选取 500 个。页面明确显示来源、启用数量和非完整词库的说明。这是语音识别加权子集，不是最新热搜词表。

此前手工整理的 208 词已删除；缺少雾凇来源信息的旧缓存不再加载。个人热词及原有开关设置保留。内部配置键 `networkHotwords` 为兼容已有设置而保留。

## 更新

- 仓库的 `dictionary` 工作流每周同步一次雾凇上游，也支持手动触发。只有同步、生成及测试通过后才提交词典数据。
- `npm run sync:rime` 将全部下载固定到同一个上游提交，保存原词典和许可，再自动生成加权子集。不要手动编辑派生词表。
- 客户端每周检查本仓库发布的派生词表，支持手动更新。下载失败继续使用本地词库；运行期间每天重试，重启也可重试。
- 更新不需要重新下载模型；只有词表数据会联网下载，不上传录音或个人热词。

## 识别行为

- 个人词权重 2.5，基础词权重 1.5，同名词保留个人权重。这些数值不是准确率最优的实验结论。
- 只有支持热词的模型使用识别权重；默认两种 Zipformer 均支持。
- 开启「清理时保留热词」时，两类词都纳入口语清理保护。
- 更新只在当前语音输入结束后应用。关闭基础词库不删除个人词。

## 纠错学习的边界

当前版本没有观察外部应用的编辑内容，也没有自动学习修改记录。

后续可先提供用户明确确认的「记住这个词」，将修正后的词保存为个人热词。若实现自动检测，需要关联本次语音输入所在的输入框、输入前后文本及编辑范围，并区分识别纠错与用户改写。Windows UI Automation 的支持取决于目标应用，不能保证覆盖所有软件。
