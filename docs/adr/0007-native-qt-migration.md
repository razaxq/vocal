# ADR-0007：C++ 业务逻辑与 Qt Quick/QML 界面

- 状态：实施中，原生开发预览已建立；尚未替换正式版。
- 日期：2026-09-17
- 用户决策：正式开始重构；业务逻辑尽量全部使用 C++，UI 使用 Qt Quick/QML。
- 范围：Windows 先验证，架构为后续 macOS 实现保留平台边界。

## 原因

Vocal 安装体积的主要组成是 Electron/Chromium 和原生推理运行库。
仅替换前端框架不能移除 Chromium。采用 Qt Quick，不使用 Qt WebEngine。
UI 更换不会减少识别模型权重，也不能直接证明运行内存或安装包减少多少。
最终体积必须在功能、模型和架构一致的正式部署包上测量。

## 边界

| 层 | 技术与职责 |
|---|---|
| 界面 | QML：布局、动画、文案、状态绑定、向 C++ 发起操作 |
| 应用服务 | C++：录音会话、模型切换、超时、空闲卸载、配置、历史、模型管理、更新 |
| 识别/纠错 | 独立 C++ 进程；C ABI sherpa-onnx，ONNX Runtime C API |
| 平台接口 | C++ 抽象：全局输入监听、全屏判断、目标输入；Windows 用 Win32，Mac 后续用 Objective-C++ |
| 开发工具 | CMake、PowerShell；Python 仅用于 SDK 安装及测试，不进入产品运行链路 |

QML 不读写配置/历史文件，不处理录音采样，不创建推理实例，不发起模型下载，
不做触发判定，不访问 Windows/macOS 系统 API。状态校验必须在 C++ 完成，
不能仅依赖按钮禁用。

QtCore 的信号槽、JSON、文件和进程 API 可以用于业务服务，无需为了“原生”
重复实现基础库。业务代码和界面仍通过明确接口连接。

## 当前实现

目录：`native/`，独立 CMake 构建；保留 Electron 源代码、启动方式与回归检查。v1.0.0 的发布工作流已改接 Qt 构建，云端 CI 首跑通过。

```text
Qt Quick settings / overlay
            |
      AppController (C++)
       /       |        \
Settings   AudioCapture   Platform + TriggerController
History        |           Windows input / fullscreen
               |
          QProcess + timeout
               |
  vocal-native --stream-worker / --asr-worker / --correction-worker
  sherpa C ABI / ONNX Runtime C API -> shared CPU runtime
```

- 模型注册表复用 `scripts/models.json`，在编译时嵌入资源。
- 默认 Paraformer 三语；已接入 5 个离线模型的 C API 配置。
- sherpa 头文件与动态库同为 1.13.8；加载前核对运行时版本。
- 识别进程不加载 QML、不注册输入钩子；标准输入输出只传 JSON 控制协议，
  float PCM 通过生命周期受控的临时文件传输。
- 启动超时 90 秒、识别超时 45 秒，错误可重载；空闲 10 分钟卸载。
- 录音使用设备支持的格式，转换为 mono float；由 sherpa 重采样。
- 录音按静音分段，单段最长 30 秒；待处理队列最多 8 段，限制积压内存。
- Qt 配置与历史独立。使用 `QSaveFile` 原子保存；损坏配置保留原文件。
- Windows 注入前检查原目标仍在前台、不是本进程、没有其他按住的修饰键；
  拒绝时保留文本，不强制夺回焦点。
- 现有研究文档和 GPU/NPU 实验不属于这次重构；不随本阶段改变推理后端。

已接入流式/定稿/纠错独立进程、完整雾凇词表与个人热词、口语清理、AI 整理、
文字输入策略、历史、模型下载/校验/删除、自启及独立原生更新通道。
九个设置页按旧版布局、尺寸、配色和简短文案重建，提供浅色/深色与中英文。
本地预览包不含模型，不启用正式更新安装；原生配置与 Electron 配置独立。
已完成与待完成的验证以 `native/VALIDATION.md` 为准。

## 后续验收与正式切换

1. **主链路验证**：Windows 实际全局按键/鼠标 → 麦克风 → 定稿 → 悬浮条 →
   目标输入；不同 DPI、显示器、全屏、输入法、权限和焦点变化的回归。
   当前自动文字输入测试受本机 Mouse Without Borders 焦点干扰，仍待验证。
2. **识别功能等价**：现有纠错语料、连续分段、仅流式模式和定稿流程已通过；
   仍需长时间录音、多设备以及实际并发操作回归，不能据有限语料宣称准确率等价。
3. **应用功能等价**：下载/校验/安全解包/删除、文字替换保护有自动测试；
   仍需安装环境中的自启/更新，以及旧版配置与历史显式导入。
4. **macOS 最小链路**：先在 Apple Silicon 实机证明音频、ASR、全局触发、
   麦克风/输入监控/辅助功能权限和不夺焦点输入，再讨论 Intel 分发范围。
5. **部署与切换**：独立原生 SDK 下载与哈希、Qt 部署/许可证清单、签名、
   安装/卸载/自动更新、配置迁移和回滚；功能等价后再测安装大小和启动内存，
   已按用户要求接入 Qt 发布目标；实际推送标签发布仍由用户决定。

原生版尚未实现的功能保持明确缺失，不提供无效控件或回退启动 Electron。

## 与既有 ADR 的关系

ADR-0006 的“零编译依赖”继续适用于现有 Electron 开发链路。
本次用户明确选择 C++ 原生重构，因此原生**开发环境**需要编译工具；
未来面向用户的原生安装包仍应携带运行依赖，用户无需安装 Qt SDK/编译器。
