## 修复的运行问题

### 设置与安装包修复（v1.0.0 发布后，本地验证）

- 3 组 QtTest、QML lint 通过。新增 HTTP 队列测试覆盖 FIFO、重复请求、取消当前/排队/全部任务、失败后继续。
- `--smoke-settings <json>` 使用隔离配置及 Windows 窗口消息验证：热词框获得焦点后，滚轮使页面移动 72 DIP；点击外部取消焦点。浅/深色菜单截图通过人工核对。
- 实际加载流式 Paraformer、定稿 Paraformer、MacBERT：4 个进程（含界面）暂停后只剩界面，恢复成功；加载过程中关闭、已关闭状态重启均通过。测试禁用全局输入和联网维护。
- 主窗口原生圆角半径为 18 DIP；实际 Win32 region 和系统合成截图通过检查。未使用透明全窗口遮罩；未对所有 Windows 版本的阴影外观作保证。
- NSIS 显式读取 UTF-8，完成页使用中英文语言字符串。基于同一源文件的空安装测试实际翻到末页并读到“启动 Vocal”；不安装文件、不写注册表。实际安装包编译通过。
- Qt 插件迁入 `plugins/`；ZIP 在仅系统 PATH 环境中启动触发/识别/关于页，并加载实际推理 DLL 成功。未执行覆盖已有安装目录的升级验收。

证据位于忽略目录 `data/native-ui-check/settings-fixes-*`、`settings-deployment` 和 `installer-finish`。
以上为 v1.0.1 发布前本地验证记录。

### 移除旧 Electron 实现

- 旧 `src/`、Electron/Vite/TypeScript 配置、旧模型下载脚本和 Electron 测试已移除；根目录 npm 锁文件不再含任何应用依赖。
- 更新日志迁至 `resources/changelog.json`；CMake、关于页和 Release 发布脚本同步读取新路径。
- 雾凇生成器迁至 `scripts/dictionary/`，无外部依赖；完整词库重建、SHA-256、许可和多音词过滤测试通过。
- Qt 编译、3 组 C++ 测试、6 项发布脚本离线测试及 QML lint 通过。历史设计/研究资料保留，并标注旧架构文档。
- `ci.ps1 -Release` 本地流水线完成：安装器与 ZIP 构建通过，清空 SDK PATH 后的界面启动、推理 DLL 加载和 SHA-256 校验通过；证据见 `data/native-ci-check`。
- 本地 `out/`、`release/` 构建产物移入回收站；个人配置、历史和 `data/models` 未清理。未发现旧版卸载记录、常见安装目录或快捷方式。

- 全局键盘/鼠标钩子使用独立 Windows 消息线程，避免 GUI 与渲染同步阻塞系统鼠标回调；实机探针连续三次验证独立线程与退出回收。
- 设置页面鼠标滚轮使用 140ms 平滑滚动；触摸板像素滚动直接跟随，所有设置滚动区到边界即停，不回弹。
- 滚轮事件实测：屏幕报告约 165 Hz 时约 165 FPS，P95 帧间隔约 11.9ms，6 秒内未采到超过 33.4ms 的帧间隔或越界位移。此前屏幕报告 60 Hz 时连续滚动约 60 FPS；系统刷新率不同，不能据此宣称性能提升倍数。
- Windows 主窗口通过 DWM 请求原生圆角，已用系统合成窗口截图核对；保持不透明窗口，不增加全窗口透明遮罩。
- 麦克风、模型下载、资源占用进度条统一使用主题绿色；模型行恢复勾选样式、禁用“不使用”说明及下载/安装大小区分。
- 模型列表改为稳定的 C++ 列表模型；进度更新仅触发对应行变化，回归测试确认其他行与索引保持有效。
- 关于页的资源进程列表也保留行控件；内存占比在同一次采样中计算，避免刷新时重建进度条或混用新旧总量。真实窗口连续四次统计刷新验证控件身份保持不变（`--smoke-resource-refresh`）。
- 退出时先断开模型进程回调，再销毁定时器，避免退出堆错误。
- 悬浮条显式取消对设置窗口的临时父窗口关系，保证设置窗口隐藏到托盘后仍能显示。
- 悬浮条由整次录音会话控制可见性，录音结束到定稿之间不退场/重播进场。真实模型及控制器测试覆盖紧凑/完整两种布局，确认该过渡中窗口持续显示且透明度不降低。
- 按下热键时先确定悬浮条位置，窗口等待本轮首帧提交后再淡入，避免显示旧帧或从旧位置跳动。两种布局分别连续执行两轮真实模型识别，检查首帧门控、位置、旧文字清空及录音到定稿的连续显示。
- 键盘按下需稳定持续 10ms 才触发，按住模式松开立即结束；测试覆盖三种模式的短按、重复按下及等待期间的取消/设置变更/全屏限制。静默会话正常结束，不提示麦克风错误或新增历史；仍保留实际设备/识别故障提示。
- 流式、定稿、纠错独立切换；默认但尚未下载的模型完成下载后也会自动加载。
- 热词保存不重启模型，中文输入不因逐字写配置而被刷新。
- 取消会话时，已交给工作进程的录音文件保留到其读取/返回结束，避免临时文件竞态。
- 文字替换失败后不重复退格；焦点离开后，本会话不再自动恢复输入。
- 只有本程序拥有的录音修饰键可暂时释放用于输入，其他按住的修饰键会阻止输入。
- 纠错使用 Windows ICU 分词以匹配旧版 Intl.Segmenter 的词边界；无此接口时保守关闭整词候选替换。
