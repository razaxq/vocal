# 打包资源

| 文件 | 用途 |
|---|---|
| `icon.svg` | **唯一的源**。改图标只改这个，其余都从它渲染 |
| `icon.ico` | 应用、窗口和任务栏图标，16/24/32/48/64/128/256 七个尺寸 |
| `icon.png` | 256×256，给 `resources/icon.png`（PNG 备用资源）用 |

渲染 ico 之前先把内容裁到外接框再留 8.5% 的边 —— 源图四周留白较多，
而 Windows 是按整张画布缩放的，留白越多任务栏上看着越小。

托盘图标在 `../resources/`，是另一版：去掉了波形条、让「文」占满画布。
16px 下「文 + 三根波形」会糊成一团，托盘要的是一眼认出来，不是还原全图。
