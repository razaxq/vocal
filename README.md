# Vocal

**按住快捷键说话，将语音转成文字，输入到你正在使用的应用中。**

适合聊天、写邮件、记录想法和起草文档。语音识别在电脑本地完成。

[下载最新版](https://github.com/razaxq/vocal/releases/latest) · [开始使用](#开始使用) · [常见问题](#常见问题)

</div>

## 下载与安装

目前提供 **Windows 64 位（x64）版本**，需要麦克风。首次使用时需要联网下载识别模型。

**推荐使用安装版**：在 [下载页面](https://github.com/razaxq/vocal/releases/latest) 选择名称包含 `Setup`、后缀为 `.exe` 的文件，下载后按向导安装。

| 版本 | 如何使用 |
|---|---|
| **安装版（推荐）**：`Vocal-Setup-版本号.exe` | 按向导安装，适合日常使用 |
| 便携版：`Vocal-版本号-win.zip` | 解压后运行 `Vocal.exe`，适合免安装或随身携带 |

两种版本都支持在软件内更新。下载页中的 `latest.yml`、`.blockmap` 和 `Source code` 无需手动下载。

## 开始使用

1. **打开 Vocal。** 首次运行会引导你进入「识别」设置。之后可双击系统托盘中的 Vocal 图标打开设置。
2. **下载模型。** 在「识别」页下载已选中的流式模型、定稿模型和标点模型，等待下载完成。保留默认选择即可开始使用。
3. **检查麦克风。** 在同一页选择麦克风，点击「测试」，说话时确认音量有变化。
4. **试着输入。** 打开记事本，点击输入位置，按住键盘右侧的 <kbd>Ctrl</kbd> 说一句话，松开后等待文字输入。

说话时，悬浮窗会显示识别结果。默认情况下，每句话完成识别后会追加到输入位置。
键盘触发录音时可按 <kbd>Esc</kbd> 取消本次输入；为了便于撤回，录音期间请尽量不要手动移动光标或编辑同一段文字。

「触发方式」中可独立开关键盘和鼠标触发，也可同时启用。鼠标支持左键、中键（按下滚轮）或左键＋中键：按住等待后说话，松开结束。延迟默认 1 秒，可自行调整；鼠标录音不使用 Esc 取消。中键可能触发目标应用的滚动功能。

## 常用功能与设置

| 想要做什么 | 在哪里设置 |
|---|---|
| 更换快捷键、使用鼠标，或改为按一下开始、再按一下结束 | 设置 → 触发方式 |
| 更换麦克风、语言模型，或调整说话停顿时间 | 设置 → 识别 |
| 提高人名、术语的识别机会 | 设置 → 识别 → 个人热词，每行一个，点击保存 |
| 使用雾凇基础词库 | 设置 → 识别 → 雾凇词库，默认开启 |
| 减少「嗯」「呃」等口头语 | 设置 → 口语清理，可调整力度或关闭 |
| 将口述文字整理为书面表达 | 设置 → AI 整理，需要配置并启用 AI 服务 |
| 开机后自动运行 | 设置 → 通用 → 开机自启 |
| 更换深色、浅色主题 | 设置 → 外观 |
| 查看之前的识别记录 | 设置 → 历史 |

默认组合使用 **Zipformer 中文**进行实时预览，使用 **Zipformer 中英**生成最终文字。
如果经常输入英文、粤语或其他语言，可以在「识别」页根据模型的语言说明更换选择。

## 软件更新

「识别」页使用[雾凇拼音基础词库](https://github.com/iDvel/rime-ice)的完整词表，按本句读音查找相关词，辅助定稿。词库每周检查更新，离线可用，不会覆盖个人热词。
词库与个人热词仅用于 Zipformer 定稿模型。填写个人热词后点击「保存热词」，下次录音生效。

Vocal 默认在启动时检查新版本。发现更新后，「关于」旁会显示红点，进入该页点击「立即更新」即可。
更新完成后，软件会重新打开。

可以在「通用」页关闭自动检查，也可以随时在「关于」页手动检查。各版本的更新内容列在「关于」页底部。

## 隐私与联网

- **语音识别在本机完成，不上传录音。** 模型下载完成后，基础语音输入无需账号，也可以离线使用。
- **历史记录保存在你的电脑上。** 可以在「历史」页查看和删除。
- **AI 整理是可选功能。** 配置并启用后，待整理的文字会发送到你指定的 AI 服务；不配置该服务也能正常使用基础语音输入。
- **模型下载、软件更新和词库更新需要联网。** 当前下载来源为 GitHub；词库更新不会上传录音、历史或个人热词。

## 常见问题

### 模型下载慢或失败怎么办？

先确认网络可以访问 GitHub，再尝试重新下载。软件会显示下载进度和失败提示。
部分模型下载包较大，下载大小与安装后的占用可能不同，以界面显示为准。

### 说话后没有文字怎么办？

先确认「识别」页所需模型已下载完成，并通过麦克风测试检查是否收到了声音。
然后在普通权限运行的记事本中试用，确认光标位于输入框内。
部分应用或以管理员权限运行的窗口可能无法接收文字。

### 识别结果不准确怎么办？

尽量减少背景噪声，选择与说话语言匹配的模型。常用的人名、地名和专业术语可以加入热词表。
识别结果仍可能有误，发送消息或保存重要内容前，请检查文字。

### 还没说完就断句了怎么办？

在「识别」页调大「停顿多久算一句」，为思考和换气留出更长时间。

### 软件占用内存较多怎么办？

识别模型运行时需要占用内存。可以在「识别」页设置「空闲释放内存」；不需要实时预览时，也可以关闭流式模型，仅保留定稿模型。
当前资源占用可在「关于」页查看。

### 安装时提示无法验证发布者怎么办？

当前安装包尚未进行代码签名，Windows 可能显示此提示。请确认文件来自本项目的 [下载页面](https://github.com/razaxq/vocal/releases/latest)。
